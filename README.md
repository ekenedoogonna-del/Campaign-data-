# Campaign-data-
Campaign Data Performance Analysis

Project Overview

This project involved analyzing campaign performance data using Microsoft Excel. The primary objective was to clean and organize the dataset, evaluate campaign and channel performance, identify the campaign type and channel that generated the highest number of new customers, uncover performance trends, and present the findings through an interactive dashboard.

Tools & Techniques

* Microsoft Excel
* Data Cleaning & Preparation
* Excel Formulas
* PivotTables
* Data Analysis
* Data Visualization
* Dashboard Development

Dataset

Campaign Raw Data

The original campaign dataset provided by the company for analysis.

Campaign Cleaned Data

The cleaned and organized version of the dataset. The data was prepared for analysis and subsequently used to create PivotTables, calculate performance metrics, and develop the dashboard.

Analysis Performed

* Cleaned and structured the campaign dataset for analysis.
* Checked for missing, inconsistent, and inaccurate data.
* Calculated overall campaign and channel performance scores.
* Compared campaign types and marketing channels based on performance.
* Identified the campaign type and channel that generated the highest number of new customers.
* Used PivotTables to summarize and analyze campaign performance.
* Created a dashboard to visualize key performance metrics and findings.

Key Findings

The analysis identified the highest-performing campaign type and marketing channel in terms of new customer acquisition. The dashboard provided a clear visual representation of campaign performance and helped highlight areas of stronger customer acquisition.

Conclusion

This project demonstrates my ability to clean, analyze, and visualize data using Microsoft Excel. It also highlights my ability to use formulas, PivotTables, and dashboards to transform raw data into meaningful insights and communicate analytical findings effectively.
